P2P Tutoring Marketplace
Overview

P2P Tutoring Marketplace is a beginner-friendly decentralized application (dApp) built on the Aptos blockchain using Move language.

The platform allows tutors to register themselves and students to book tutoring sessions securely using blockchain-based payments.

Features
Tutor registration
Blockchain-based payments
Session booking
Wallet integration
Session tracking
Aptos smart contract

Frontend

Smart Contract Functions
register_tutor()

Allows tutors to register and set pricing.

book_session()

Allows students to pay tutors directly.

update_price()

Allows tutors to modify session price.
